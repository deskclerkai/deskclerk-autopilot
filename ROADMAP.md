# Roadmap

This is a direction, not a promise. Security and user-reported regressions take priority.

## v0.1 — Current

- Shared inbox across multiple company numbers
- Contact ownership, custom segments and public pool
- Campaigns with consent and template checks
- Owner / manager / agent roles and read-only seats
- WhatsApp Cloud API webhook and coexistence echo handling
- AI manual / draft / autopilot modes with handoff
- Twelve analytics boards and nine filter dimensions
- Docker and local deployment
- Full API, fuzz, edge, performance and browser test suite

## v0.2 — Next

- Self-service password change and session management
- PostgreSQL adapter for teams above SQLite's concurrency comfort zone
- Docker Compose profiles for Caddy and Nginx
- Media messages: images, documents and voice notes
- Safer import flow with column mapping and consent checks
- More granular audit filters and CSV export

## v0.3 — Later

- Additional knowledge-base adapters behind the same contract
- Webhook subscriptions for CRM and ERP systems
- Scheduled reports and daily digest email
- Message template variable validation before submission
- More languages in the UI

## Not planned

- Unofficial WhatsApp gateways
- Automatic mass messaging without opt-in
- Multi-tenant SaaS in the core repository
- A hosted service operated by the maintainers in this repository

## How to influence the roadmap

Open an issue with the problem, the workflow and the outcome you need. Concrete user problems carry more weight than feature names.

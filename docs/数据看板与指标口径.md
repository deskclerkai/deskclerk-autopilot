# 数据看板与指标口径

> 适用系统：DeskClerk AI Autopilot
> 最后更新：2026-11-12
> 关联文档：[客户池与筛选](./客户池与筛选.md)、[客户分层](./客户分层.md)、[公海机制](./公海机制.md)

## 一、筛选维度

看板顶部有两行筛选，全部可以叠加。

| 维度 | 取值 | 作用范围 |
|---|---|---|
| 时间 | 近 7 / 30 / 90 天，或自定义起止日期 | 消息、任务、AI 日志、新增客户 |
| 负责人 | 老板/主管可见全部或本组；按成员筛选 | 客户、会话、AI 日志 |
| 来源 | Website / Facebook / Instagram / Ads 等 | 客户 |
| 国家 | 客户档案里的国家 | 客户 |
| 标签 | 标签管理里的标签 | 客户 |
| 分层 | 系统分层 + 自定义分层 | 客户 |
| 成交阶段 | 当前行业口径的阶段 | 客户 |
| 团队 | 接待组 | 客户负责人所属团队 |
| 号码 | 公司 WhatsApp 号码 | 会话、消息、AI 发送 |
| 授权 | 已授权 / 已退订 | 客户 |

日期筛选优先于快捷时间：填了开始或结束日期，就按自定义区间算。

## 二、指标口径

| 指标 | 怎么算 | 注意 |
|---|---|---|
| 客户数 | 当前筛选命中的客户总数 | 不是"本期内新增" |
| 新增客户 | `created_at` 落在区间内的客户 | 受其他筛选影响 |
| 已发送 | 区间内已完成任务的 `sent` 合计 | 任务按公司口径，不按个人拆分 |
| 已送达 | 区间内已完成任务的 `delivered` 合计 | 同上 |
| 回复率 | `replied / delivered` | 分母为 0 时显示 0 |
| 已成交 | 当前筛选里成交状态属于成功态的人数 | 成交状态是当前值，没有成交时间字段 |
| 成交金额 | 成功态客户的 `deal_value` 合计 | 销售可能看不到金额 |
| 会话数 | 筛选客户名下的会话数 | 受号码权限限制 |
| 未读 | 这些会话的 `unread` 合计 | — |
| 平均回复 | 同一会话里，客户来信到下一次我方发出的平均分钟数 | 只统计区间内的消息 |
| AI 处理量 | 区间内 `ai_logs` 条数 | 受客户筛选影响 |
| 自动处理率 | `decision=auto / AI 处理量` | 不是"回答正确率" |
| 转人工率 | `decision=handoff / AI 处理量` | 包含无依据、投诉、明确要人工 |
| 命中知识 | `sources` 非空的 AI 日志占比 | 不是准确率 |
| 平均耗时 | `latency_ms` 平均 | 包含外部知识库网络时间 |
| 退订率 | 退订人数 / 当前筛选客户数 | 退订是永久状态 |
| 公海数 | 当前筛选里无负责人且未退订的客户 | — |

## 三、板块

| 板块 | 回答什么问题 |
|---|---|
| 8 个 KPI | 客户、发送、回复、成交、金额、会话、AI、退订 |
| 每日消息 | 每天发出/收到多少条，AI 发出多少 |
| 客户来源占比 | 客户从哪来 |
| 转化漏斗 | 发送 → 送达 → 回复 → 成交 |
| 各分层表现 | 每个分层命中、可发送、成交、金额 |
| 按国家 | 哪些国家客户多、成交多 |
| 按标签 | 哪些标签客户多、成交多、退订多 |
| 按负责人 | 每个销售手里多少客户、成交多少 |
| 按团队 | 每个接待组的客户和成交 |
| 按号码 | 每个号码的会话、未读、收发、AI 发送 |
| 成交阶段分布 | 当前 pipeline 卡在哪个阶段 |
| 触达任务表现 | 每个任务的发送、回复、回复率 |
| AI 接待效果 | 处理量、自动、草稿、转人工、拦截、命中知识、耗时 |

## 四、权限

- 销售（agent）不能打开看板，接口返回 403。
- 主管只看本组数据；老板看全部。
- 号码筛选只出现该用户有权限的号码。
- 成交金额按字段权限隐藏；销售看不到金额时，相关板块不显示金额。

## 五、已知口径限制

1. **任务发送量不按个人/国家/标签拆分。** 任务是对一个分层发的，没有记录"这条消息发给了哪个销售"。只有按分层筛选时，任务才跟着分层过滤。
2. **成交没有时间。** 当前成交状态是实时值，所以"本期成交"实际是"当前筛选里处于成交状态的人"，不是"本期新成交"。
3. **平均回复只算区间内。** 客户在区间前发、区间后回的，不计入。
4. **AI 命中知识 ≠ 答对。** 命中只说明引用到了知识，是否正确仍要人工抽检。
5. **自定义日期最长画 120 天。** 超过 120 天的区间，图表只画最后 120 天，但汇总数字仍按完整区间算。

## 六、接口

`GET /api/analytics`

参数：

- `range=7d|30d|90d`
- `start=YYYY-MM-DD`、`end=YYYY-MM-DD`（任一存在即走自定义）
- `agent`、`channel`、`country`、`tag`、`segment`、`deal`、`team`、`number`、`opt=in|out`

返回：

- `series`：每日 `out` / `in` / `new`
- `channel_split`、`funnel`
- `segments`、`by_country`、`by_owner`、`by_team`、`by_tag`、`by_stage`、`by_number`
- `campaigns`、`ai`
- `facets`：筛选下拉的选项
- `prev`：上一周期的对比值

## 七、前端行为

- 每次改筛选都会重新请求；用请求序号丢弃过期响应，避免快速切换时旧数据覆盖新数据。
- 点 KPI 可以跳到客户池、会话台、触达任务或 AI 页。
- 点分层表一行，跳到分层详情。
- 点负责人名字，直接按这个负责人筛选。

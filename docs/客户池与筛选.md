# 客户池与筛选

> 适用系统：DeskClerk AI Autopilot
> 最后更新：2026-11-09
> 关联文档：[客户分层](./客户分层.md)、[公海机制](./公海机制.md)、[员工与客户归属](./员工与客户归属.md)

## 一、客户池是什么

客户池 = **全量客户**。左边按条件筛，右边看单个客户的档案、标签、最近沟通。

公海只是客户池里的一个视图（只看没负责人的），不是另一个库。

## 二、六个视图

| 视图 | 规则 |
|---|---|
| 全部 | 能看到的所有客户 |
| 活跃 | 30 天内有联系 |
| 沉默 | 超过 30 天没联系 |
| 已成交 | 成交状态属于成功态 |
| 未打标 | 一个标签都没有 |
| 公海 | 没有负责人 |

视图上方的数字会随数据实时变化。销售登录时，视图只统计他自己名下的客户（公海除外）。

## 三、筛选条件

点「⚙ 筛选」展开筛选面板，五项可以叠加：

| 筛选 | 取值 | 说明 |
|---|---|---|
| 标签 | 全部标签 | 选一个标签 |
| 国家 | 客户里出现过的国家 | 自动生成，不是固定列表 |
| 来源 | Website / Facebook / Instagram / Ads… | 自动生成 |
| 授权 | 不限 / 只要已授权 / 只要已退订 | 合规排查用 |
| 排序 | 默认 / 最近联系优先 / 最久未联系优先 / 最新加入优先 | |

再配合顶部搜索框（姓名、号码、国家，边打边筛）。

**筛选之间是 AND**：比如"国家＝UAE + 只要已授权 + 标签＝汽配"，三个都满足才出现。

被选中的筛选数量会显示在「筛选」按钮上，右侧的「清理」一次清空。

## 四、从别处带过来的筛选

| 来源 | 带过来的条件 | 怎么清 |
|---|---|---|
| 数据看板 → 点某个销售 | 负责人 | 顶部黄色条「清除」 |
| 数据看板 → 点某个成交状态 | 成交状态 | 顶部黄色条「清除」 |
| 客户分层 → 去客户池看 | 分层规则 | 顶部蓝色条「清除」 |

分层筛选和普通筛选可以同时存在。

## 五、单个客户能看什么

右侧客户档案包含：

- WhatsApp 号码（默认打码中间几位）、来源、授权时间、所在分层
- **负责人**：老板/主管是一个下拉框，直接改；销售只看到名字
- 成交状态、成交金额（销售看不到金额）
- 标签（可增删）
- 最近沟通记录（最近 20 条）

操作：领取（无主时）、放回公海、标记/恢复退订、更新状态、指派负责人。

## 六、分页与导出

- 一页 20 条，底部上一页/下一页。
- 设置 → 工作区 → 「导出联系人 CSV」，导出当前账号能看到的全部客户。

## 七、接口

```
GET /api/contacts?view=all&kw=&limit=20&offset=0
    &owner=3&deal=Lead&tag=1&country=UAE&source=Website&opt=in&seg=5&sort=newest
GET /api/contacts/{id}
PATCH /api/contacts/{id}          # 改成交状态 / 金额 / 备注
POST  /api/contacts/{id}/assign   # 指派负责人（老板/主管）
```

参数为空即不生效；`opt` 取值 `in` / `out`；`sort` 取值 `newest` / `oldest` / `created`。

## 八、注意

- 「未打标」视图用的是全站标签，任何一个人打上标签，这个客户就从该视图消失。
- 销售能看到的客户范围由权限决定，筛选是在这个范围里再筛，不会越权。
- 公海视图里每行的「领取」按钮受公海规则约束，不是每行都能点，详见公海文档。

## 九、标签的增删改（全流程）

标签是全站共用的一份。三种入口：

| 动作 | 在哪做 | 说明 |
|---|---|---|
| 新建 | 设置 → 标签管理 → 「＋ 新建标签」 | 建出来是空标签，客户数 0 |
| 新建（顺手） | 客户档案 → 「＋ 添加标签」→ 新建 | 建完直接打到这个客户身上 |
| 改名 | 标签管理 → 「改名」 | 所有客户的标签一起改，不会丢关联 |
| 合并 | 标签管理 → 「合并」 | 把 A 并进 B：A 身上的客户都挂到 B，A 删除 |
| 删除 | 标签管理 → 「删除」 | 只删标签本身，客户不删 |

注意事项：

- 删除标签**不会**删客户，只是这些客户不再带这个标签。
- 改名和合并是全站生效，不需要逐个客户改。
- 领取范围、分层规则里引用的标签，删掉后那一条条件就不再生效（分层会少命中人）。

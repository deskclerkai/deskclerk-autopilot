# 权限矩阵（角色 × 功能）

> 产品：DeskClerk AI Autopilot
> 最后更新：2026-11-12
> 结论：**已按角色实测定稿；只读账号不能做任何写操作。**

## 一、角色

| 角色 | 说明 |
|---|---|
| 老板 owner | 全部数据、全部设置 |
| 主管 manager | 本组数据；可指派本组成员；不能改系统设置 |
| 销售 agent | 自己名下客户；本组号码的会话；只能回自己的会话 |
| 只读账号 | 角色仍是主管/销售，但 `can_reply=0`，**所有写操作拒绝**（`403 read_only`） |

## 二、页面可见性

| 页面 | 老板 | 主管 | 销售 | 只读 |
|---|---|---|---|---|
| 会话台 / 公海 / 客户池 / 分层 / 模板 | ✅ | ✅ | ✅ | ✅（只读） |
| AI 助手（接入/人设/接待方式） | ✅ | 可看可测 | ❌ | 可看，不能改 |
| 触达 / 团队 / 看板 | ✅ | ✅ | ❌ | ✅（只读） |
| 设置 | ✅ | ✅（写操作多数仅老板） | ❌ | ✅（只读） |

## 三、数据范围

| 数据 | 老板 | 主管 | 销售 |
|---|---|---|---|
| 客户 | 全部 | 本组成员名下 | 自己名下 + 公海 |
| 会话 | 全部号码 | 本组被授权号码 | 本组被授权号码 |
| 号码 | 全部 | 本组被授权号码 | 看不到号码管理页 |
| 成员列表 | 全部 | 本组成员 | 无权访问 |
| 操作日志 | 全部 | 本组成员 + 系统动作 | 无权访问 |
| 触达任务 / 看板 | 全部 | 全公司（公司级资产） | 无权访问 |
| 设置 | 全部 | 只读（敏感值打码） | 只返回成交状态 + 会话规则 |

## 四、写操作权限

| 操作 | 老板 | 主管 | 销售 | 只读 |
|---|---|---|---|---|
| 指派客户 | ✅ 任何人 | ✅ 本组成员 | ❌ | ❌ |
| 认领客户 / 会话 | ✅ | ✅ | ✅ | ❌ |
| 放回公海 | ✅ | ✅ 本组 | ✅ 自己的 | ❌ |
| 标记退订 | ✅ | ✅ 本组 | ❌ | ❌ |
| 修改客户 / 标签 | ✅ | ✅ 本组 | 认领后 | ❌ |
| 新建/改/删标签 | ✅ | ✅ | 只能新建 | ❌ |
| 新建/改/删分层 | ✅ | ✅ | ❌ | ❌ |
| 新建模板 | ✅ | ✅ | ❌ | ❌ |
| 发起触达 | ✅ | ✅ | ❌ | ❌ |
| 会话 AI 托管开关 | ✅ | ✅ | ✅ 本组会话 | ❌ |
| 采用 AI 草稿 | ✅ | 需先成为负责人 | ✅ 自己的会话 | ❌ |
| 转移客户 | ✅ | ✅ 本组 | ❌ | ❌ |
| 添加/停用/删除成员 | ✅ | ❌ | ❌ | ❌ |
| 改系统设置 / 公海规则 | ✅ | ❌ | ❌ | ❌ |
| 改 AI 配置 / 知识库同步 | ✅ | ❌ | ❌ | ❌ |

## 五、后端硬校验（不是前端隐藏）

| 接口 | 规则 |
|---|---|
| `GET /api/contacts` | 按角色过滤数据范围 |
| `GET /api/conversations` | 按号码授权过滤；严格模式只允许负责人回复 |
| `GET/PATCH /api/settings` | 销售只返回 `deal_stages` / `inbox`；写仅老板 |
| `GET /api/numbers` | 主管只返回本组号码 |
| `GET /api/audit` | 主管只看本组成员 + 系统动作 |
| `POST /api/contacts/{id}/assign` | 主管只能指派本组成员 |
| `POST /api/contacts/{id}/release` / `optout` | 主管只能操作本组客户 |
| `POST /api/conversations/{id}/messages` | 只读 403 `read_only`；非负责人 403 `not_owner` |
| `POST /api/ai-drafts/{id}/accept` | 只读、非负责人均拒绝 |
| 所有写接口 | 只读账号一律 403 `read_only` |

## 六、已知的"公司级"共享

以下两项对主管是**全公司可见**，属于有意设计，不是越权：

- 触达任务列表与发送记录（公司统一营销活动）；
- 数据看板的触达汇总（公司级指标）。

客户与会话仍按本组隔离。

# Governance

## Model

DeskClerk AI Autopilot is **maintainer-led**. The maintainers set the roadmap, review contributions and make the final decision when consensus is not reached.

The project is not a foundation project and does not claim to represent the WhatsApp or open-source community as a whole.

## Roles

| Role | Responsibilities |
|---|---|
| Maintainer | Merges pull requests, cuts releases, handles security reports, sets roadmap |
| Contributor | Submits issues, documentation, tests and code |
| User | Deploys the software and reports reproducible problems |

Maintainers are listed in the repository's commit history and release notes. New maintainers are added by existing maintainers based on sustained, constructive contributions.

## Decisions

- Small changes: lazy consensus in the pull request.
- User-visible or architectural changes: an issue first, then a pull request that links to it.
- Security fixes: handled privately, released as soon as practical.
- Breaking changes: require a major version under Semantic Versioning and a migration note.

## Releases

- Versions follow Semantic Versioning.
- Release notes follow Keep a Changelog.
- Database changes include backup and migration instructions.
- The full test suite must pass before a release.

## Roadmap

The public roadmap is in [ROADMAP.md](ROADMAP.md). It is a direction, not a contract. Priorities can change based on security, user reports and maintainer capacity.

## Security

Security reports follow [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.

## Code and brand

- Code contributions are accepted under Apache-2.0.
- Brand use is governed by [TRADEMARK.md](TRADEMARK.md).
- Community behavior is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Commercial services

The maintainers may offer commercial hosting, integration or brand licensing. Commercial work does not change the rights granted by the Apache-2.0 license.

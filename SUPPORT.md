# Support

## Documentation first

- [README](README.md) — what the project is, quickstart, Docker, configuration.
- [docs/](docs/) — WhatsApp setup, coexistence, pool rules, permissions, AI integration, analytics.
- [FAQ](README.md#faq) — common questions about scope, official APIs and data ownership.

## Where to ask

| Topic | Channel |
|---|---|
| Bug with reproduction steps | GitHub Issue |
| Feature idea or design question | GitHub Issue or Discussion |
| Security vulnerability | [SECURITY.md](SECURITY.md), privately |
| Deployment question | GitHub Discussion |
| Commercial hosting or brand licensing | Contact the maintainers |

## What to include in a bug report

- version or commit;
- deployment method: local, Docker, reverse proxy;
- steps to reproduce;
- expected and actual behavior;
- relevant logs with secrets and personal data removed.

## What is not supported

- unofficial WhatsApp gateways;
- bypassing Meta template review or opt-in rules;
- use of the DeskClerk name or logo for a competing product;
- guaranteed delivery, account survival or platform policy outcomes.

## Response expectations

This is a maintainer-led open-source project. Issues are reviewed on a best-effort basis. Security reports are prioritized.
